# FolderFlow NG — Downloads

Public download center for **FolderFlow NG**, the professional hot-folder document
processing and print automation application for Windows.

- **Download page:** https://djsurs-penny.github.io/folderflow-downloads/
- **Releases:** https://github.com/djsurs-Penny/folderflow-downloads/releases

Every release ships two assets:

| Asset | Purpose |
|-------|---------|
| `FolderFlowNG_Setup_<version>.exe` | Full installer (standalone x64, includes Windows service + Office converter) |
| `FolderFlowNG_<from>_to_<to>.zip` | Update patch for existing installs |

The download page reads the latest release automatically, so a new version appears
on the site as soon as it is published here.
