Feature highlights

  • Drop files into any watched folder — automatically converted, printed or archived
  • Native PDF printing with watermark / header / footer stamping
  • Microsoft Office conversion (DOCX, XLSX, PPT) to PDF via the background service
  • Print accounting with per-user quotas and monthly usage reports
  • Enterprise security: DPAPI-encrypted secrets, parameterized SQL, signed SHA-256 updates
  • Runs as a Windows service — works with no user logged in
  • Drag & drop files directly onto hot folders in the dashboard
